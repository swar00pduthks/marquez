# Getting Started with Marquez

Welcome to **Marquez**, an open-source metadata service for the collection, aggregation, and visualization of a data ecosystem's metadata. Marquez provides end-to-end visibility into data pipelines by tracking lineage, schema changes, and job execution history.

## Why Marquez?

| Capability | Description |
|---|---|
| **Data Lineage** | Trace upstream and downstream dependencies across jobs and datasets automatically. |
| **Metadata Versioning** | Track schema changes and dataset versions over time for auditing and troubleshooting. |
| **OpenLineage Native** | Built on the [OpenLineage](https://openlineage.io) standard — an open framework for data lineage collection. |
| **Rich Web UI** | Explore lineage graphs, job run histories, and dataset metadata in a modern web interface. |
| **REST API** | Programmatic access to all metadata via a well-documented HTTP API. |
| **Multi-Scheduler Support** | Works with Apache Airflow, dbt, Spark, Flink, and other data tools through OpenLineage integrations. |

## Key Concepts

Before diving in, familiarize yourself with these core concepts:

### Namespaces
A **namespace** is a logical grouping for datasets and jobs. Namespaces help organize metadata by team, project, or environment (e.g., `production`, `staging`, `analytics-team`).

### Datasets
A **dataset** represents a table, file, or stream in your data ecosystem. Marquez tracks dataset schemas, owners, descriptions, and version history.

### Jobs
A **job** represents a data transformation or pipeline step. Jobs have inputs (consumed datasets) and outputs (produced datasets), forming the basis of lineage tracking.

### Runs
A **run** is a single execution of a job. Each run records its start time, end time, status (running, completed, failed, aborted), and the specific dataset versions consumed and produced.

### Lineage
**Lineage** is the graph of dependencies between jobs and datasets. It answers questions like: *"What datasets does this job consume?"*, *"What downstream jobs are affected if this dataset's schema changes?"*, and *"What was the last successful run that produced this dataset?"*
